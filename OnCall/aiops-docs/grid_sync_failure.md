# 电网数据同步失败率过高告警处理方案

## 告警定义

- 告警名：`GridDataSyncFailureRateHigh`
- 级别：严重
- 条件：`grid_data_sync_failure_rate` 连续 15 秒超过 20%
- 演示场景：`sync_failure`

## 诊断步骤

1. 使用 `list_active_alerts` 确认活动告警和触发时间。
2. 使用 `query_grid_data_sync_metrics` 获取同步失败率与队列深度趋势。
3. 使用 `query_grid_service_status` 排除整个服务不可用。
4. 使用 `search_log` 查询同一时间窗口内的同步失败、下游接口和数据校验日志。

## 常见原因

- 下游主站接口不可用或响应异常。
- 数据格式或完整性校验失败。
- 认证配置或连接参数错误。
- 重试积压进一步推高队列深度。

## 处置建议

1. 检查下游接口连通性和返回码。
2. 抽样核对失败数据的校验结果。
3. 修复配置或依赖后重试失败任务。
4. 确认失败率回落到 20% 以下且队列不再增长。
